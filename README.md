# 🍔 Yumm – Food Delivery App

**Yumm** is a full-stack food delivery application built with **Flutter**, integrated with **Firebase** for authentication and database services, and **Cloudinary** for image storage. It supports two user roles: **Admin** and **Customer**, offering full functionality from browsing food to managing orders.

---

## 🚀 Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Firestore, Authentication, Storage)
- **Image Hosting:** Cloudinary
- **Auth:** Firebase Email/Password with Email Verification

---

## 🖥️ Responsive UI

Yumm supports responsive design for a smooth experience across different screen sizes including smartphones and tablets. Layouts and widgets adjust dynamically using `MediaQuery` and `LayoutBuilder` to maintain a consistent, touch-friendly UI.

---

## 👥 User Features

- ✅ Register with email & password (requires email verification via link)
- 🔐 Secure login with Firebase Auth
- 📋 Browse food menus and view item details
- 🛒 Add items to cart
- 🏠 Select delivery address
- 💰 Choose payment method (Cash on Delivery)
- 📦 Place orders
- 📖 View order history and live order status
- ❌ Delete past orders from history
- 🙍‍♂️ Profile section to:
  - Change profile picture
  - Log out
  - Delete account

---

## 🛠️ Admin Features

- ➕ Add food items to the menu
- ❌ Delete food items
- 📑 View all customer orders
- 🔄 Update order status (e.g., pending, confirmed, out for delivery)

## 🧪 Environment Variables

Create a `.env` file in the root of your project and add:

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
CLOUDINARY_UPLOAD_PRESET_USER=userprofile
CLOUDINARY_UPLOAD_PRESET_ITEM=food_item_upload
